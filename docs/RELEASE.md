# 0.11.0 · 环游与互动

- 扩展到约2.45×1.8 km漫游范围，新增连接村落的环线道路与五处米制地标雏形：金字塔、埃菲尔铁塔、比萨斜塔、卢浮宫、天安门。
- 全域地图、快速到达、探索打卡；第一人称支持抬头观察高塔，漫游中可调昼夜天气。
- 路人停留、过街、车辆停让、受击踉跄和逃跑；可叫停并夺取路人车辆驾驶，下车后留在当前位置。
- 轿车、SUV、两厢车、皮卡、厢式车外形，电动车30 km/h、汽车200 km/h；速度相关转向和连续小步碰撞检查。
- 五种猫、四种犬外形与原有宠物互动；保留自家布局和装修方案。

这是离线开放世界原型，地标不是完整实景复原；只有简化展厅，不含完整地标室内和登顶。警觉与车辆停车为本次会话状态，探索印章和装修方案本机保存。
