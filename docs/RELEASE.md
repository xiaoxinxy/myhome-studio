# 0.12.0 · 村庄日常、山林景观与交互优化

本版重点修正严重卡顿、人物错色与坐姿，并完善从自家院落到村庄和景区的游玩内容。

- 长距离遮挡查询不再扫描海量空网格；小地图底图复用、人物与景观按距离降低细节、鸡鹅按视野提交实例。普通画质使用轻量光照，持续严重超载会降档。
- 修复NPC脸部颜色槽复用、院子座椅被提前隐藏造成的悬空观感；按实际座高调整腿部角度，占用的座椅不能重复坐入。
- 支持按住拖动/移动鼠标转向切换，窄窗口也有开关；整理导航、地图天气和动作区域，增加FPS快捷入口，保留摇杆、跳跃和低墙攀爬。
- 完善五景区及可进入的游览区域，移除雏形牌子。加入旅游大巴、站台、游客、售票厅与免费参观票。
- 村民在院内干活、茶馆和广场休息、卫生所候诊接诊、学堂读书玩耍；有独立身份、本机交谈记录和未来AI提供方接口，当前未接在线AI。
- 地图扩展至约4.1×3.2km，新增富士山主题景观、火山口与熔岩湖、雪山、杉木森林步道、观景休息点及外围道路。山坡支撑与可见网格对应。
- 保留自家布局、装修方案、原安卓签名与离线资源。高空观景平台的栏杆不会再挡住地面车辆。

71项逻辑检查及相关浏览器、最终APK断网回归通过；性能条件、结果与限制详见仓库docs/verification/verification-0.12.0.md。本机帧率不代表安卓手机表现。

这是继续打磨的离线开放世界原型，景点与自然地形为游戏化建模，未包含完整现实博物馆、真实火山模拟或完整车辆物理。覆盖安装可保留本机方案，建议先导出JSON备份。仓库与发布保持私有。
