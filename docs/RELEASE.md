# 0.12.2 · 日月天气、景区生活与碰撞

东行公路上的景区广场曾与路面共面重叠，交叉路口也叠放了重复路面。本版将铺装切为不重叠的区域，景点指示牌移到入口侧边，铁塔和博物馆的快速到达点避开候车棚。

- 晴天太阳、夜间月亮、雨雪乌云随时间和天气切换；月面带细节，云层缓慢移动。山上的雨雪跟随海拔。
- 新增348名游客、登山者和外围居民，覆盖五处景点的广场、售票区、甬道、展厅、观景台、三条完整山道、登山口和森林；外围新增更多汽车、面包车、三轮和电动车，各路段分散运行。
- 驾驶时可撞击行人，触发有限冲量、重力下落、倒地、起身和恢复过程；实体墙仍阻挡，高速子步检测避免漏撞。保留近距离交谈与原有互动。
- 新增人口使用远处合批与固定16个近处细节名额，复用人物模型；远处交通降低更新频率。动态人车空间索引减少碰撞查询，实例颜色仅在变化时上传，自动清晰度调整与场景重建分离，并缓存重型静态场景组件。

89项逻辑检查覆盖路面无重叠、游客全路线避障、登山海拔、外围车流路面归属、高速撞人、墙后遮挡、重力恢复、空间索引及原有完整山道往返。浏览器与最终离线APK的结果见 docs/verification/verification-0.12.2.md。

村落和自然地形为游戏场景，碰撞不是完整布娃娃或车辆损毁系统。实测帧时间仅代表本机短路线，首次加载、快速切换景区和不同手机仍可能出现卡顿。原签名覆盖安装；建议先导出JSON备份。仓库与发布保持私有。
