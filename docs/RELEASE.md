# 我的家 0.10.0

自家院落与村庄生活离线安卓应用。

- 独立设计的小卖铺、村部、卫生所与理发店，18种专用家具与可进入室内。
- 丁字路网、电杆电线、路沿、井盖与排水口；22辆行驶车辆和24名新增步行居民。
- 座椅、床沿和躺姿定位修正，支持起身回原站位。
- 动态人车合批、连续铺装合并、稳定的自适应分辨率控制。
- 保留自家装修方案、十二户邻居、南院、天气昼夜、驾驶与生活交互。

签名和包名沿用，可覆盖安装；Android8.0+，资源完全离线。

验证：50项逻辑测试通过，生产构建、APK签名及断网运行、图片导出、漫游和返回检查通过。电脑软件渲染测试不能代表安卓真机帧率；详细记录见docs/verification/verification-0.10.0.md。
