# 0.12.1 · 可攀登的山体与驾驶平顺性修正

此前自然景观虽已显示，人物和车辆仍使用旧地图边界，导致山脚被拦住。本版统一全域边界，将自家正门前的公交站搬到村口公共候车区。

- 富士山折返登山道，以及雪山、火山的盘山路，从入口连续通往峰顶或火口内沿。地面与脚下碰撞共用高细节三角形，加入路标、护栏导向、登顶留念、山腰雾带与峰下云海。
- 使用慢帧子步推进步行和驾驶，避免只推进50ms；同步平滑跟随镜头位置与注视点，第一人称平移直接跟随人物，避开山体和人群引发的镜头抽动。车辆随坡面调整高度和俯仰。
- 自家车辆从静态村庄的距离裁剪中分离，并按运行时位置裁剪，解决车辆开远后消失；仍保留在GLB模型导出里。
- FPS显示加入慢帧次数，提示中显示P95和峰值；后台暂停不计入动态画质降档。远处山体和村庄使用简化轮廓，近处山路使用精细高度网格。

80项逻辑检查通过，包括三条完整路线实际上山、原路下山，不用传送替代。浏览器检查覆盖真实山脚行走、山路/峰顶视野、驾驶模型持续显示、原有景区交互、手机布局与导出。最终原签名APK另做断网回归。详见docs/verification/verification-0.12.1.md。

地形仍为压缩的游戏场景；护栏为视觉导向，未实现完整车辆悬挂或翻车物理。本机短路线采样不能保证所有手机和地点都无卡顿。覆盖安装前建议导出JSON备份，仓库与发布保持私有。
