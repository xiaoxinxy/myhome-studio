# 从自家院落出发的小开放世界

我建议把核心定位定为「乡村生活 + 公路旅行」：家是长期经营的据点，村庄提供熟悉的人和日常工作，外围地标提供旅行目标。先让一段半小时的体验好玩，再继续增加地图面积。

## 第一阶段：做出能反复玩的半小时

1. **送货赚钱 → 添置家具 → 升级车辆 → 去旅行。** 小卖铺取包裹，送到三户不同邻居家；按距离、准时和货损结算。收入能买家具、修车、种子与食物。第一笔收益应在五分钟内产生。
2. **村民有名字、日程与记忆。** 上班、赶集、回家、避雨，关系影响价格和任务；受攻击会逃避并记住玩家，夺车需要找回、归还或付出代价。现版本的警觉值只是开端，还没有完整警察系统。
3. **车有用途与驾驶手感。** 电动车适合村内，三轮车适合拉货，汽车负责远行；加入刹车灯、悬挂、发动机声、损伤和维修。200 km/h 留给长直公路，村内交通保持低速。
4. **家的变化看得见。** 家具布置、炕、庭院花草与猫窝成为收入出口；昼夜和天气影响种植、送货、路况与NPC行为。保存角色、任务、资产、停车位置和时间。

验收标准：不靠自由拍照，玩家也能完成接单、行驶、交付、消费和回家这一整条流程；退出后能接着玩。

## 第二阶段：让探索有回报

- 把现有五个地标逐个打磨成独立的小区域：观景、简短室内、找物、摄影挑战、旅行纪念品。先完成一个高质量样板，避免五处都只有外壳。
- 公路旅行加入加油/充电、路边摊、服务站、岔路与导航；地图上的距离和景观变化应支撑旅途。
- 猫狗有领养、喂食、信任、跟随和回家行为。自家三只猫有独立习惯；不把换毛色当成完整宠物玩法。
- 菜地与果园加入种植、成熟、天气影响与集市价格，和送货经济共享资源，避免孤立的按钮小游戏。

## 第三阶段：增加长期目标

修缮老屋、经营小卖铺/车行、建造扩建、节庆和季节活动。村民关系和车辆收藏形成可持续目标。多人联机放到单人存档、碰撞和任务稳定之后。

## 性能优先级

- 按区域加载建筑和内饰，远景保留低面数轮廓，靠近才加载细节；不要让全地图全部内饰常驻。
- 近处人物完整更新，中距离低频更新，远处只推进日程。交通和导航先做局部空间索引，再增加人口密度。
- 以一台明确型号的中端安卓机持续跑30分钟为基准，记录平均帧率、1%低帧、内存、温度、进出区域卡顿；桌面软件渲染不能替代真机结果。
- 把存档版本迁移、地图分块、角色状态、任务系统和渲染分开。若最终追求大规模物理、复杂动作与车辆，先比较原生游戏引擎迁移成本，再继续堆场景。

## 0.11.0 的实际边界

当前是可漫游的游戏原型。地标采用统一米制，外观为程序几何雏形，集中在虚构的地标公园，不是现实世界地图；卢浮宫只有简化展厅，其余没有完整室内、楼梯或可登顶系统。攻击为无血腥的挥拳、踉跄与逃跑，不是完整格斗。夺车、停车位置和警觉是会话状态；探索印章与原装修方案保存在本机。地图范围已扩大，外围内容密度仍较低，不能把范围面积当成已精细制作的内容面积。
