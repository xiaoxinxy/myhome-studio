## 实现

公共场所使用独立体量、屋顶、招牌、玻璃入口和室内平面。小卖铺分零售收银/粮油仓储；村部有服务大厅/议事室/阅览办公；卫生所有候诊登记/独立诊疗/观察/药房；理发店有镜台理发区/洗发毛巾间。新增18种专用陈设，药柜内部为分类药盒，毛巾柜为叠放织物，饮料柜为玻璃门。

实景参考：[杂货铺](https://smiletaiwan.cw.com.tw/article/510)、[中国摄影家协会老理发店](https://www.cpanet.cn/detail_picdetail_132829.html)、[农业农村部村卫生室](https://www.shsys.moa.gov.cn/ncggfw/202001/t20200109_6334574.htm)、[奉贤卫生室](https://www.fengxian.gov.cn/gzms/20230207/36632.html)。本地程序建模提炼实景特征，未打包网上照片，保持离线。

路网为三条东西道路、三处连接支巷、两处尽头巷及田间土路，交会点均为丁字结构。新增分段路沿、人行道、排水箅子、检修井盖、电杆、横担、绝缘子和下垂电缆。路口和院门保留通道。渲染、小地图、地面高度和电杆碰撞共享道路定义。

新增22辆背景车辆（汽车/送货车/三轮/电动车）、24名路人，保留原居民及街猫狗。人车持续沿路线移动，人物迈步；靠近玩家停让，驾驶状态增加停车距离，招呼后停留三秒再恢复。背景车辆可示意/鸣笛，自家车辆仍可驾驶。

椅子按实际座面与前沿摆放髋部、双腿；取消额外下沉。床沿坐和躺下分开，头部留在床垫范围内；炕从室内临边坐下，躺下按枕头方向。背包收起，起身恢复第一次坐下前的站位，切换坐躺不覆盖该点。躺姿镜头比较多方向与周边射线，避开附近柜子后仍可手动转向。

## 性能

动态人车跨角色共享实例绘制，保留腿部动作、原始运动状态和逐实例点击。手动视锥筛选后压紧实例数量；使用复用矩阵和可见性缓存，不逐帧设置React状态。连续人行道/路沿合并，箅子缝隙改为本地纹理，细小路面不投射阴影；电线共用一组线段，室内保持距离加载。

发现并修复画质回弹：原Canvas固定dpr参数会在提示或其他界面状态更新后覆盖自适应分辨率；RenderBudget内部记录已到下限，因而无法再次降低。现在Canvas与预算控制器共享同一DPR状态。浏览器实测降至0.75后，点击行驶车辆触发提示仍保持0.75，动态实例点击正常。

清理前签名0.9与0.10 APK资源在Chrome SwiftShader、1280×900、均衡街道视角比较。清除相机提示后切换画质，待实际绘图缓冲稳定一致（589×468），30帧预热、40帧采样；完整记录 apk-performance-0.10-comparison.json，含两APK哈希。

| 指标 | 0.9 | 0.10 |
|---|---:|---:|
| 平均帧耗时 | 193.4ms | 195.6ms |
| 中位帧耗时 | 186.6ms | 188.3ms |
| P95帧耗时 | 245.1ms | 250.8ms |

新增内容后平均耗时增加约1.2%，此短样本中基本持平；不声称全路线帧率提升。开发中不同绘图缓冲的中间记录不可直接比较；最后记录通过了缓冲尺寸相同断言。自适应状态冲突修复另由交互回归证明。以上为电脑软件渲染，不是安卓真机FPS；未测实体手机长期掉帧。
