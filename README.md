# 我的家 · 院落与村庄工作室

根据自家照片与草图制作的3D院落、村庄生活和装修预览应用。当前版本 **0.12.2**，独立离线安卓App；此仓库为私人项目，包含现场照片与视频。

## 安装

从 [GitHub Release v0.12.2](https://github.com/xiaoxinxy/myhome-studio/releases/tag/v0.12.2) 下载「myhome-0.12.2.apk」（本机文件名为「我的家-0.12.2.apk」）。Android8.0+，系统WebView需支持WebGL2。模型、照片、视频和交互资源随包提供，首次启动无需电脑或网络。原签名覆盖安装可保留本机方案；卸载或清除数据会删除本机数据，建议先导出JSON备份。

本机安装包在「安装包/」，APK与校验文件同时作为Release附件保存，二进制安装包不进入Git历史。

## 功能

- 自家正房、东西厢房、前后院、两车棚与南院鸡鹅菜园；尺寸按照片估算。
- 十二户不同布局的邻居，以及小卖铺、村部、卫生所、理发店、菜地与果园，均有室内陈设。
- 丁字路网、支巷、电杆电线、排水箅子、井盖和路沿，街道有持续行驶的车辆与走动的居民。
- 重做人物骨架、面部、衣着与动作；第一/第三人称漫游、摇杆/WASD移动、跳跃和低墙攀爬。电脑支持「按住鼠标／移动鼠标」一键切换，默认按住拖动；可锁定鼠标，第一人称可大幅抬头。
- 村民在院内干活、茶馆喝茶、广场玩耍和坐着聊天、学堂读书、卫生所候诊与接诊；活动定时切换。每位主要村民和路人有独立身份与本机交谈记录，当前为离线规则对话，已预留 AI 提供方接口。
- 开关门柜、坐下/躺下/起身、蹲下摸猫、车辆驾驶与骑行。漫游靠近物件后使用附近提示或 F 互动；观察/装修模式保留直接点选和拖动。
- 场所取货、问诊模拟、理发换色、浇灌采收与摘果；背景人车可招呼与停让。
- 约 4.1 × 3.2 km 可漫游范围，五处米制地标集中在村边文化景区：铁塔三层观景台、斜塔旋梯和钟楼、金字塔甬道石室、卢浮宫两翼艺术展厅、城楼展厅。为游戏化建模，非测绘级实景复原。
- 富士山主题雪顶山体、火山口与熔岩湖、雪山、杉木林步道、观景休息点和外围公路。自然山体是压缩的游戏地形，并非现实山体尺寸复刻；山坡支撑跟随渲染网格。
- 客运站、邮政驿站、维修铺、茶馆、文化学堂、集市、公共卫生间、广场、田野林带、山坡与进出小径。主要公共设施可进入并使用陈设。
- 两辆实际行驶的旅游大巴连接村口、客运站和五景区，提供候车亭、游客、售票厅、免费参观票、快进候车、上车和到站下车；保留全域地图、快速到达与旅行印章。
- 五种汽车外形、30 km/h 电动车和最高 200 km/h 汽车；路人停留、过街、让行、受击逃跑，路上车辆可夺取驾驶。
- 五种猫与四种犬的外形，保留自家三只猫；简单警觉值及冷却，车辆停放位置在本次会话中保留。
- 晴天太阳、夜间月亮、雨雪乌云；348名额外景点游客、登山者和外围居民，山道随地形行走，展厅和观景台有人参观。
- 车辆可撞击行人，触发抛起、落地、起身和恢复行走；碰撞保持实体墙阻挡，高速按子步检测。
- 昼夜、天气、画质调节，家具布置、材质改造、撤销重做、本机保存与JSON备份，PNG/GLB/CSV导出。

## 开发

需要Node.js20.19+或22.12+。

```sh
npm ci
npm run dev
```

打开 http://localhost:5180/ 。手机浏览器调试使用终端显示的局域网地址。

```sh
npm test
npm run build
npx playwright test
```

交互测试与scripts/check-walking-performance.mjs需要开发服务。正式体验可停止开发服务，执行npm run build后运行npm run preview -- --port 5180，减少调试开销。

浏览器测试需要安装Chromium（npx playwright install chromium），也可通过PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH指定本机Chrome。离线APK测试需先构建APK，或下载当前Release的APK到「安装包/」。测试生成文件写入artifacts/和test-results/，不进入Git。scripts/check-*.mjs保留了场所、坐躺、车流及画质专项检查（check-walking-performance.mjs 为步行性能采样），需本机Chrome和已启动的开发服务。

## 安卓构建（Windows）

安装JDK17+，然后执行：

```sh
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-android.ps1
npm run android:build
```

输出到「安装包/」，构建会校验签名、资源路径、ZIP对齐和离线资源。首次准备Android工具需要网络。原签名密钥与凭据仅保存在本机.android-signing/，不会上传；在其他电脑继续发布覆盖升级包前，需要从安全备份恢复该目录。切勿替换现有签名密钥。

本机可执行npm run android:download，打开终端中的8090端口地址下载安装包。此入口只用于下载，安装完成后App独立运行。

## 运行与性能

均衡画质保留基础纹理，精细画质提供完整法线、粗糙度细节与实时阴影；低性能设备可选择流畅优先。场景启动时准备材质，漫游交互只检查附近提示；移动中固定绘图分辨率，停稳后再按预算调整，避免行走时反复重建缓冲区。分块裁剪、遮挡和静态/动态合批减少提交量；模型导出时会恢复完整源网格。本次驾驶记录使用本机默认图形后端，不代表安卓真机帧率。

## 模型参考与验证

自家布局以现场资料与使用者确认信息为准；邻居和公共设施为参考实景的设计，非实测村庄复原。街巷参考[山西襄汾丁村](https://main.dmctv.com.cn/villages/14102310001/Index.html)；场所参考[杂货铺](https://smiletaiwan.cw.com.tw/article/510)、[老理发店](https://www.cpanet.cn/detail_picdetail_132829.html)、[村卫生室](https://www.shsys.moa.gov.cn/ncggfw/202001/t20200109_6334574.htm)。网上照片未作为在线依赖打包。

[0.12.2验证记录](docs/verification/verification-0.12.2.md)包含80项逻辑测试、场所/开放世界流程、分批浏览器回归和最终APK断网验证；后续玩法和当前原型的边界见 [开放世界扩展建议](docs/OPEN_WORLD_ROADMAP.md)。

## 本轮性能与修正

长距离遮挡查询不再按距离扫描大量空网格；自家家具远离后提前裁剪，小地图底图复用，材质预热阶段按需渲染。均衡与流畅模式保留基础纹理、实例配色、透明度和发光，改用轻量漫反射光照；精细模式使用原PBR细节。远处走动的人物使用简化模型，靠近后恢复面部衣着细节。持续极低帧率时会降低分辨率，精细模式严重超载时会自动回到均衡，可手动调整。

修复人物合批槽复用导致的脸部颜色错乱、院内座椅提前隐藏造成的悬空观感，并按座高计算腿部角度。漫游工具分为顶部导航、右侧地图天气和底部动作，左上/手机左下显示FPS并可快捷切到流畅优先。软件渲染采样不能代表手机实际帧率，仍不承诺所有设备稳定60FPS。

当前检查见[0.12.2验证记录](docs/verification/verification-0.12.2.md)。技术依据：[Three.js轻量光照材质](https://threejs.org/docs/pages/MeshLambertMaterial.html)、[R3F性能指南](https://r3f.docs.pmnd.rs/advanced/scaling-performance)。

本机有独立显卡时，可设置MYHOME_SOFTWARE_RENDER=0使用默认图形后端做交互回归；强制软件渲染的长流程测试会明显占用CPU。请将测试与前台3D体验分开运行。

0.12.2 修正：公交站迁至村口公共区域；行走/车辆统一使用全域边界。三座山加入可步行登顶再下山的路线，雪山与火山有盘山路和导向护栏、路标、雾带与峰顶观察点。移动和驾驶拆成物理子步，镜头位置/注视点同步平滑；自家车辆独立于村庄静态区域的距离裁剪，开远后保持显示。FPS旁提供慢帧次数，按钮提示显示P95和峰值。
