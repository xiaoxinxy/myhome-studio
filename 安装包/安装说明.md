# 我的家 · 0.10.0

当前安装文件：我的家-0.10.0.apk。SHA256校验值见同目录SHA256.txt。

## 安装

GitHub私有仓库的[0.10.0发布页](https://github.com/xiaoxinxy/myhome-studio/releases/tag/v0.10.0)提供myhome-0.10.0.apk下载（与本机中文文件名APK内容一致），需登录有权限的账号。也可使用电脑本机当前目录下的APK，或运行npm run android:download，通过同一Wi-Fi的手机访问终端提示的8090端口地址。

直接覆盖安装，无需卸载，可保留原本机方案。需要Android8.0+及支持WebGL2的系统WebView；安装完成后首次启动和日常使用均无需电脑、无需网络。卸载或清除数据会删除本机方案，建议先在App里备份JSON。

## 使用

- 点「小人漫游」进入；左侧摇杆移动，右侧拖动区转向。电脑使用WASD/方向键、Q/E和Shift。
- 「去哪里」可到自家、邻居、公共场所、南院、菜地和果园。进入室内保持完整墙顶，需剖视布置时主动切换模式。
- 靠近物件点「互动」或直接点物件；椅子可坐，床/炕可坐到床沿或躺下，点起身恢复原站位。
- 门、冰箱和柜门可开关；靠近猫可蹲下抚摸。
- 自家汽车/三轮/电动车可驾驶或骑行，前推加速、后拉倒车、左右转向，可刹车和下车；背景车辆只支持示意与停让。
- 小卖铺取货、村部公告、卫生所问诊模拟、理发店换色、菜地浇灌采收与果园摘果均可体验。
- 「昼夜与天气」调节时刻、天气和画质；流畅优先适合性能较弱的手机。
- 布置模式支持移动家具、材质调整、撤销重做、方案保存/导入/导出。PNG/GLB/CSV可从工具栏导出。
