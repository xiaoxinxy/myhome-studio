# 我的家 · 0.12.2

当前安装文件：我的家-0.12.2.apk。SHA256校验值见同目录SHA256.txt。

## 安装

GitHub私有仓库的[0.12.2发布页](https://github.com/xiaoxinxy/myhome-studio/releases/tag/v0.12.2)提供myhome-0.12.2.apk下载（与本机中文文件名APK内容一致），需登录有权限的账号。也可使用电脑本机当前目录下的APK，或运行npm run android:download，通过同一Wi-Fi的手机访问终端提示的8090端口地址。

直接覆盖安装，无需卸载，可保留原本机方案。需要Android8.0+及支持WebGL2的系统WebView；安装完成后首次启动和日常使用均无需电脑、无需网络。卸载或清除数据会删除本机方案，建议先在App里备份JSON。

## 使用

- 点「小人漫游」进入；左侧摇杆移动，右侧拖动区转向。电脑使用WASD/方向键、Q/E和Shift；移动鼠标即可转向，空格跳跃，C 攀爬低矮障碍，V 切换视角，可选择锁定鼠标。
- 「去哪里」可到自家、邻居、公共场所、南院、菜地和果园。进入室内保持完整墙顶，需剖视布置时主动切换模式。
- 漫游时靠近物件点附近「互动」或按 F；椅子可坐，床/炕可坐到床沿或躺下，点起身恢复原站位。
- 门、冰箱和柜门可开关；靠近猫可蹲下抚摸。
- 自家汽车/三轮/电动车可驾驶或骑行，前推加速、后拉倒车、左右转向，可刹车和下车；路上车辆可先叫停再接管驾驶。
- 小卖铺取货、村部公告、卫生所问诊模拟、理发店换色、菜地浇灌采收与果园摘果均可体验。
- 「昼夜与天气」调节时刻、天气和画质；流畅优先适合性能较弱的手机。
- 布置模式支持移动家具、材质调整、撤销重做、方案保存/导入/导出。PNG/GLB/CSV可从工具栏导出。

安装包不纳入Git历史，当前版本作为GitHub Release附件保存；旧安装包与临时产物已从项目目录清理。原签名密钥仅保存在电脑.android-signing/，请单独安全备份，不要上传。

0.12 新增：主要村民与路人可交谈并分别保存近期记录，目前使用本机规则对话，AI 尚未连接。村民有院内劳动、坐下聊天、玩耍、上课、接诊候诊等活动。

村口与客运站有旅游大巴；靠近候车亭选择目的地，可等待或快进上车，到站自动下车。五处村边景区有售票厅，可领取参观票、乘电梯去铁塔观景台、游览斜塔钟楼与旋梯、进入甬道、艺术展厅和城楼展厅。景区是游戏化制作的游览区域。

电动车最高30 km/h，汽车最高200 km/h；探索印章、门票和交谈记录自动保存。本次人车位置、临时行为和停车位置在重启后复原。

## 新版操作

电脑顶部「转向」按钮切换按住鼠标或移动鼠标转向；手机保持右侧拖动视线。空格跳跃、C攀爬、WASD移动、F互动。顶部目的地新增山林景观。FPS按钮可快捷切到流畅优先；精细模式在持续严重超载时会自动回到均衡。性能实际取决于手机和WebView，本机软件渲染测试不代表手机帧率。

0.12.2：村口公共候车站在自家东侧约120米处，不再位于院门口。选择山林目的地后，沿浅色山道和路标步行上山；雪山与火山的盘山路线也可驾驶，弯道请减速。山顶可以登顶留念、远眺；山腰雾带会影响能见度。FPS的平均值可能掩盖短暂卡顿，新版同时统计慢帧、P95与最大帧耗时。

0.12.2：日月随时刻升落，雨雪形成乌云，高山也有跟随海拔的降水。景点、展厅、观景台、山道与外围道路补充人车；车辆撞击行人后有抛起、落地、起身和恢复过程。修正东侧公路与广场铺装重叠、道路交叉口闪烁。新增人群远处合批、近处复用16个精细模型名额；自动清晰度调整不再重建整片场景。首次加载与区域切换仍可能有短暂峰值。
